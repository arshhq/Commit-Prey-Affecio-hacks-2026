# 🛡️ TrustLens

> Trust before connection.

TrustLens is a privacy-first safety layer for online dating and social discovery. It helps users spot fake profiles and romance scams *before* they get emotionally or financially invested.

**Built for FFECIO HACKS '26 — Problem Statement #4: Trust Before Connection**

## ✨ Features
- 🖼️ **Photo Authenticity Check:** Error Level Analysis, metadata and pixel checks, all client-side
- 💬 **Scam Chat Detector:** flags love-bombing, off-platform requests, urgency and money asks using the Claude API
- 📊 **Live Risk Meter:** real-time risk score with clear, gentle warnings
- 🔐 **Privacy by Design:** photos never leave the device; only SHA-256 hashes are used

## 🧱 Tech Stack
Next.js 14 (App Router), TypeScript, Tailwind CSS, HTML5 Canvas API, Web Crypto API, Claude API, Lucide React, Framer Motion, Zod, Vercel
